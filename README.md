# Baltena2

## Start the complete application

From the workspace root:

```powershell
npm install
npm run dev
```

This starts:

- Frontend: http://localhost:3001
- Backend: http://localhost:4000

To check both services:

```powershell
npm run check
```

To start only one service:

```powershell
npm run dev:frontend
npm run dev:backend
```

In VS Code, use **Terminal > Run Task > Start Baltena (frontend + backend)**.
